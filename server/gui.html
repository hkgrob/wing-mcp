Push a show file to the live desk. It writes node by node with a read-back after each one, so the desk changes as it runs. Never push during a show. Run a dry run first.

The command profile is the desk's own list of every parameter, type and range, and every write is checked against it. Build one on any desk whose model has none yet (a full WING or a Compact), and again after a firmware update. Read-only; takes several minutes.
